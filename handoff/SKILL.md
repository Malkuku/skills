# Handoff 中文版

把当前对话整理成一份交接文档，让新的 agent 能继续工作。

## 输出要求

创建一份交接文档，内容包括：

- 当前目标
- 已完成的工作
- 尚未完成的工作
- 关键决策
- 重要文件路径
- 当前风险或阻塞
- 下一位 agent 应优先使用的 skill，如果有

## 写入方式

将文档保存到通过临时文件命令生成的路径。

在写入之前，先读取该文件，避免覆盖已有内容。

## 避免重复

不要重复已经存在于其他工件中的完整内容，例如：

- PRD
- 计划文档
- ADR
- issue
- commit
- diff

如果相关信息已经存在，引用路径或 URL 即可。

## 参数处理

如果用户传入了参数，把参数视为下一轮会关注的任务说明，并据此调整交接文档重点。
