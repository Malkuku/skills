# Reader Regression Examples

此文件用于开发评审和回归测试，不参与正常运行。示例重点检查行为边界，不要求模型逐字复现输出。

## E1. 未读材料时不得先替用户规划

### 输入

用户上传一份长技术文档，并说：“我想找到能解决性能问题的部分，帮我安排阅读。”

### 错误行为

- 没有读取目录或正文就推荐某几个章节；
- 根据“性能问题”套用通用缓存、并发和数据库路线；
- 先询问一组泛化知识水平问题，再开始看材料。

### 期望行为

1. 调用 `INITIALIZATION.md`。
2. 先读取材料结构和代表性内容，确认文档实际讨论哪些性能问题。
3. 将用户目标映射到材料中的候选范围。
4. 深读候选范围和必要前置后，再制定阅读路线和校准相关基础。

## E2. 不为了初始化通读所有章节

### 输入

材料共有十五章。用户只想理解其中一个 API 的认证与错误处理。

### 错误行为

- 在开始回答前深读十五章；
- 为所有章节生成知识点和题库；
- 因为尚未读完整份文档而拒绝处理局部目标。

### 期望行为

- 先通过目录、概述和代表性片段认识材料结构；
- 定位认证、错误码、调用示例及必要前置；
- 深读这些内容；
- 明确当前结论只覆盖该 API 的目标范围。

## E3. 已初始化的材料不重复初始化

### 前置状态

同一材料已经完成侦察，当前目标范围和必要前置已知。

### 输入

用户问：“继续看下一小节。”

### 错误行为

- 重新读取 `INITIALIZATION.md`；
- 再次输出材料类型、全文路线和用户画像问卷；
- 清空当前知识点状态重新开始。

### 期望行为

- 复用现有导航；
- 确认下一小节是否仍在当前目标范围内；
- 直接深读并继续领读。

## E4. 目标变化时只增量侦察

### 前置状态

当前只侦察并深读了部署部分。

### 输入

用户改为询问索引迁移策略。

### 错误行为

- 假装部署部分的导航足以支持迁移问题；
- 重新完整初始化全文；
- 仅凭已有通用知识回答材料中的迁移设计。

### 期望行为

- 判断新目标超出现有范围；
- 增量侦察索引、别名、迁移和兼容性相关部分；
- 更新必要前置；
- 深读后再回答。

## E5. 用户目的必须经过材料校验

### 输入

用户说：“我想通过这篇论文学习如何在生产环境部署这个模型。”

材料实际只讨论理论方法和离线实验，没有部署内容。

### 错误行为

- 强行从实验设置推导生产部署教程；
- 因为用户明确提出目标，就假装材料能够满足目标。

### 期望行为

- 先读材料并确认其范围；
- 明确论文可以支持方法理解和实验复现，但不足以系统学习生产部署；
- 根据用户需要，选择继续读论文可覆盖的部分，或说明还需要其他资料。

## E6. 知识校准必须围绕目标内容

### 前置状态

AI 已深读 OpenSearch alias 相关内容，目标是帮助用户安全切换索引版本。

### 错误行为

询问：“你是什么职业？”“你学过搜索引擎吗？”“你觉得自己基础怎么样？”

### 期望行为

优先根据已有对话判断；必要时只确认会改变讲解路线的前置，例如：

- 是否已经区分 index 与 alias；
- 是否理解读别名和写别名的用途；
- 当前更需要理解机制还是排查现有错误。

## E7. 三道题不能自动代表单元通过

### 前置状态

当前目标有六个核心知识点。用户答对三道应用题，只直接验证了其中两个知识点。

### 错误行为

- 因为用户连续答对三题，宣布“你已经掌握这一节”；
- 把应用表现自动扩展为定义、边界和其他知识点也已掌握。

### 期望行为

```text
已验证：K2、K4
未验证：K1、K3、K5、K6
当前只能确认相关场景中的应用能力，不能判断整个目标范围已经掌握。
下一轮优先检查尚未覆盖的核心项。
```

## E8. 答对结论但解释错误

### 输入

用户选择了正确方案，但理由把两个概念当成同义词。

### 错误行为

- 只看最终答案正确，将相关知识点标为已验证；
- 忽略错误理由并直接推进。

### 期望行为

- 承认方案结论正确；
- 将相关知识点标为“不稳定”；
- 指出概念边界错误；
- 纠正后使用不同表述或新场景复测。

## E9. 不需要复杂矩阵

### 输入

当前目标包含五个核心知识点。

### 错误行为

建立“知识点 × 复述 × 边界 × 关系 × 应用 × 证据 × 反例”的大表，计算权重和小数覆盖率，并在后续对话中反复维护。

### 期望行为

只保留：

```text
K1 已验证
K2 不稳定：适用条件仍混淆
K3 未验证
K4 已验证
K5 未验证
```

题型用于获得证据，不作为单独的长期状态维度。

## E10. 单轮题量不等于总测试量

### 输入

规则要求每轮只展示 1–3 道题，当前仍有未验证核心知识点。

### 错误行为

问完三题就结束检测。

### 期望行为

- 每轮仍只展示少量问题；
- 回答后更新知识点状态；
- 继续针对未验证或不稳定项提问；
- 直到达到当前目标的完成条件，或用户主动选择结束。

## E11. 简单目标不要过度测试

### 输入

用户只想从文档中确认某个参数的默认值及适用条件。

### 错误行为

- 强制建立完整阅读单元；
- 提取 5–8 个知识点并安排多轮考试；
- 要求用户证明掌握整个配置章节。

### 期望行为

- 读取参数定义及必要上下文；
- 直接给出默认值、适用条件和范围说明；
- 只有用户明确要学习或检测掌握时才进入提问流程。

## E12. 用户质疑后必须收窄判断

### 输入

用户指出：“你只问了两个问题，为什么说我已经掌握这一章？”

### 错误行为

- 辩解问题具有代表性；
- 继续问下一章的问题；
- 维持原有整体掌握结论。

### 期望行为

- 承认评价范围过大；
- 改为只确认两个问题实际验证的知识点；
- 列出仍未验证的核心项；
- 暂停推进，由用户选择补测、回看或继续。
