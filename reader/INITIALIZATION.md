# Reader Initialization

## 用途

此文件只在当前材料没有可复用的初始化结果时调用。

初始化的目的不是提前深读全文、生成完整题库或建立复杂知识图谱，而是通过真实阅读获得对材料的基本判断资格，并形成足以支持当前目标的导航。

初始化完成后，正常领读、答疑、测试和推进只使用 `SKILL.md`。只有材料或目标越过现有导航范围时，才增量更新初始化结果。

## 初始化判断

需要初始化：

- 新材料第一次进入对话；
- 只有文件名或零散片段，尚不知道材料实际内容；
- 现有导航范围不足以支持用户的新目标；
- 新版本或新增章节改变了结构、结论或前置关系；
- 先前记录明显不完整、错误或无法定位当前内容。

可以复用：

- 同一材料继续阅读下一小节；
- 用户针对已知范围提问；
- 用户回答测试题；
- 用户要求回看、总结或补测当前目标；
- 用户目标虽有调整，但仍落在已经侦察并读取过的范围内。

## 初始化原则

1. **先读材料，后映射目的**：可以提前知道用户想解决什么，但在材料侦察前不得据此断言材料重点或阅读路线。
2. **先侦察，后深读**：侦察负责认识材料结构和候选内容；深读只针对当前目标和必要前置。
3. **不强求全文地图**：当前目标不需要的章节可以只知道其存在和大致功能，不必提前解析。
4. **不制造虚假全局理解**：只读过目录、摘要或片段时，必须保留范围说明和不确定项。
5. **导航应被目标修正**：材料侦察完成后，再判断用户目的在材料中对应什么、材料是否真的能满足它。
6. **初始化结果保持轻量**：只保留后续导航需要的信息，不预生成全文问题库、所有章节知识点或复杂依赖矩阵。

## 第一步：材料侦察

对每份新材料，先读取足以认识其实际内容的结构与代表性信息。

优先读取：

- 标题、材料类型和版本信息；
- 目录、章节标题、文件树或接口索引；
- 摘要、前言、引言、概述或 README；
- 总结、结论、设计目标或使用说明；
- 各主要部分的代表性片段；
- 用户明确提到的术语、问题或目标在文中的位置及上下文。

不能因为目录中出现某个标题，就假装已经理解该章节。目录用于定位，结论必须来自实际内容。

### 短材料

材料较短且完整阅读成本低时，可以直接完整阅读，不必为了形式强行分层初始化。

### 长材料

材料较长时，先建立浅层结构认识，再选择性深入：

```text
读取目录 / 文件树 / 摘要
→ 抽查主要部分的开头、结尾和代表性内容
→ 识别材料主线、主要对象和明显依赖
→ 结合用户目的定位候选范围
→ 深读候选范围和必要前置
```

如果材料没有目录或结构混乱，通过标题、段落主题、接口、代码模块或论证转折建立临时边界，并明确这只是工作性划分。

## 第二步：形成材料认识

侦察后，内部至少回答：

```text
这份材料实际在处理什么问题？
主要由哪些部分组成，各自承担什么功能？
作者、规范或项目如何从前提推进到方法、结论或实现？
哪些判断目前只是目录级认识，尚未经过深读？
```

此时不要提前生成：

- 全文问题库；
- 所有章节的能力点；
- 面向不同人群的多套完整路线；
- 精细对象索引或高维知识依赖图；
- 未经目标筛选的长篇结构化总结。

## 第三步：结合用户目的定位

材料侦察完成后，再把用户表达的目的映射到材料。

判断：

1. 用户目标在材料中是否有直接对应内容；
2. 哪些内容直接服务目标；
3. 哪些内容是理解目标所必需的前置；
4. 哪些内容只提供背景、案例或扩展；
5. 哪些内容当前可以不读；
6. 材料是否缺少完成该目标所需的信息。

如果用户没有明确目的，基于材料实际内容提供少量真实可行的阅读方向，再让用户选择；不要在未读材料时套用“入门、考试、工作”通用菜单。

如果用户目标与材料不匹配，应明确说明。例如材料只描述接口结果，却不解释内部原理，就不能承诺通过该材料系统学习实现机制。

## 第四步：确定目标范围并深读

把候选内容转化为实际阅读范围。深读至少覆盖：

- 用户目标直接依赖的正文；
- 关键术语的定义位置；
- 结论所依赖的上下文；
- 必要的前置章节、接口契约、配置约束或证据；
- 容易误读的限制、例外或反例。

阅读单元可以跨越章节，不必机械按照目录顺序。

只有经过深读的内容，才可以用于：

- 建立当前目标的核心知识点；
- 设计知识水平问题；
- 进行系统领读；
- 判断用户是否掌握；
- 对材料观点作较强结论。

## 初始化记录

初始化结果只需维护以下轻量记录：

```text
材料范围：当前已侦察到哪里，哪些部分尚未查看
材料主线：材料实际解决的问题和主要组织方式
当前目标：用户本轮想完成什么
目标范围：已经定位并需要深读的部分
必要前置：理解目标范围所需的其他内容
不确定项：仍需进一步阅读才能确认的判断
```

不要维护复杂的持久化矩阵。进入目标单元后，核心知识点及三态状态由 `SKILL.md` 管理。

## 增量更新

目标改变时，先判断新目标是否落在现有导航范围内：

- 已在范围内：直接定位并深读，不重新初始化全文。
- 超出范围：只侦察新增相关部分，并更新材料范围、目标范围和必要前置。
- 新内容推翻旧认识：修正已有导航，并明确哪些先前判断失效。

## 超长材料与子任务

确有必要使用子 agent 或分块处理时，每个分块只返回：

```text
本块范围
本块功能
主要内容
与当前目标的相关性
与其他部分的必要依赖
尚不能确定的内容
```

不要要求每个分块都生成题库、能力点、路线、难度评级和完整总结。局部阅读者不得替全文下结论，主 agent 只合并当前导航真正需要的信息。

## 初始化完成条件

同时满足以下条件即可结束初始化：

1. AI 已经通过实际阅读认识材料的基本范围和组织方式；
2. 能说明当前判断覆盖了哪些内容、尚未覆盖哪些内容；
3. 已把用户目的映射到材料中的候选范围；
4. 已确定下一步需要深读的内容和必要前置；
5. 没有把目录级认识包装成正文级理解。

初始化完成不代表全文已经掌握，只代表 AI 已获得足以开始目标化阅读的导航。

## 对外输出

默认不展示冗长的内部初始化记录。首次对外输出可根据任务裁剪为：

```text
我目前确认这份材料主要处理：...
与你当前目标直接相关的是：...
需要一起看的前置是：...
暂时不用读的是：...
我尚未确认的是：...
接下来先深入：...
```

用户只要求局部答案且相关内容已经定位时，可以直接回答，同时简要标明理解范围，不必展示完整路线。
