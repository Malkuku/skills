# Reader Templates

模板是默认骨架，不是强制表格。用户只问局部问题时，只调用对应模板，不要强行展开完整流程。

## T1. 读者画像校准模板

```text
在制定阅读路线前，我需要先校准你的阅读场景和基础。

你的阅读场景可能是：...
你的目标可能是：...
我会用几个问题判断你的基础：
1. ...
2. ...
3. ...

根据你的回答，我会把阅读路线调整为精读、略读、可跳过或需要回看的不同部分。
```

## T5. 交互提问模板


```text

注意：这道题答得好，只能证明你在这个场景中能迁移相关概念，不等于整节已经掌握。

```

引导模式：

```text

1. 先确认 ...
2. 再比较 ...

```

```text

```

## 路线标记规则

- **必读**：直接服务读者目标，缺失后无法完成任务。
- **精读**：包含核心概念、机制、证据、接口、契约或高频考点。
- **略读**：提供背景、铺垫或低优先级细节，只需理解大意。
- **可跳过**：与当前目标关系弱，跳过不影响本轮目标。
- **后读**：适合在理解主线后再看，如案例、扩展、争议、优化细节。
- **需要回看**：当前单元依赖此前内容，读者基础不足或回答暴露漏洞时使用。

## 掌握度 5 档标准

1. **未掌握**：无法复述核心概念，或回答明显偏离原文。
2. **初步理解**：能说出大概意思，但概念边界、因果关系或适用条件不稳定。
3. **基本掌握**：能准确复述核心内容，区分关键概念，指出基本适用条件和常见误解。
4. **能够迁移**：能把内容用于新场景，并解释为什么这样用。
5. **能够批判性理解**：能区分原文观点、证据、推论和个人评价，并指出材料局限或争议。

## 范围化评估规则

掌握度必须绑定范围。推荐格式：

```text
你对「某概念 / 某能力点」达到 X 档。
你对「某章节整体」暂不能判定，原因是尚未测试 ...
```

禁止表达：

```text
你已经掌握这一节。
```

除非已经覆盖：

1. 概念复述
2. 概念边界
3. 关键关系
4. 至少一个场景迁移
5. 至少一个易错点或反例

## 默认推进规则

- 未掌握 → 不进入下一单元，先回看或重讲。
- 初步理解 → 可以进入下一单元，但必须先补强关键漏洞，并明确“只是局部通过”。
- 基本掌握 → 可以建议进入下一单元，但仍应询问用户是否需要补测或总结。
- 能够迁移 → 可以进入应用练习或更高阶内容，但不自动等于章节完整掌握。
- 能够批判性理解 → 可以进入总结、输出、讨论或研究型任务。

慢速领读模式下，即使达到基本掌握，也默认给出推进选择，而不是自动进入下一单元。
